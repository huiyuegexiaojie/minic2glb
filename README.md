# Minic2GLB

把本地沙盒游戏存档转换成内嵌贴图的三维模型（GLB），可直接在 Blender 等工具中打开、编辑与渲染。

Convert local sandbox-game saves into textured GLB models.

## 功能

**存档读取**

- 直接读取本机存档目录，支持多维度、多区域文件
- 索引损坏或标识不明时，可从文件本身恢复读取参数
- 一次扫描同时取出方块、方块实体与群系信息

**模型还原**

- 常见方块按原始形状重建：立方体、七档高度薄板、竖板、玻璃片连接、楼梯三模板、四类斜板及其内外转角、围栏、树枝、门窗、家具、植被
- 支持方块朝向、上下半格、连接状态、生长阶段等存档属性
- 群系染色、方块染色、透明与自发光材质
- 地图自带的复制方块与自定义体素模型

**资源读取**

- 可直接从本机游戏安装包按需读取模型与贴图，无需预先解包
- 支持四套官方材质包，可按存档记录自动选择，也可手动指定
- 资源缺失时跳过单个部件并生成清单，不影响整张图导出

**导出**

- 单文件 GLB，贴图内嵌，无需附带图片目录
- 支持按 X/Z 框选区域与 Y 高度范围裁剪
- 可输出详细报告：绘制清单、状态统计、资源清单、未适配项、耗时
- 失败或取消不覆盖已有的同名输出

**界面**

- 内置卫星图预览，可平移、缩放、框选导出范围
- 显示当前选区的方块数与预计范围
- 导出进度、耗时、跳过数量可视化

## 联网校验

本软件在以下三个时刻会向固定地址发起网络请求，读取启用状态：

| 时机 | 行为 |
|---|---|
| 启动软件 | 请求启用状态页 |
| 读取卫星图 | 请求启用状态页 |
| 开始导出 | 请求启用状态页 |

判定规则：返回内容为 `yes` 时继续；为 `no`、请求失败、或内容无法识别时，**本次操作停止**。

这意味着：

- **离线环境无法使用**，包括无网络、公司内网限制、代理拦截、以及该地址在你所在网络不可达的情况。
- 该地址不可用（域名到期、被占用、服务变更）时，所有使用者都会无法启动，需等待版本更新。
- 请求仅发送到该固定地址，不向其他服务器上传存档内容、导出结果或本机文件。软件不会读取与本机目录无关的位置。

如果你无法接受这一机制，请不要下载使用。

## 快速开始

> 以下流程适用于恢复发布后的版本。当前不提供下载。

**图形界面**

1. 启动后点击"选择地图"，从列表中选择存档；或"打开目录"直接指定地图目录。
2. 等待卫星图加载完成。
3. 左键拖动平移，滚轮缩放，右键拖动框选 X/Z 范围。
4. 设置导出最低 / 最高 Y。只导建筑时，把最低 Y 设在地面之上。
5. 选择资源来源与材质包（默认自动）。
6. 点击"导出 GLB"，选择保存位置。

**命令行**

本版本仅提供图形界面，发行包内不含独立的命令行程序。`minic2glb-worker.exe` 是界面用于执行导出任务与回传进度的后台进程，由程序自行调用，不需要手动运行，也不接受用户参数。

如果你需要批量或自动化导出，请通过 Issues 说明场景，后续版本再评估是否开放。

## 输出说明

- 一格等于一个建模单位，Y 轴向上。
- 贴图内嵌于 GLB，移动文件不会丢失材质。
- 勾选报告后，会在 GLB 同目录生成 `<文件名>-report`：
  - `export-settings.json`：本次选区、高度、形态、选中方块数
  - `draw.tsv`：实际绘制清单
  - `block-list.tsv` / `states.tsv`：方块与状态统计
  - `unsupported-blocks.tsv`：仍使用占位模型的方块
  - `timings.json`：各阶段耗时
- 出现跳过的部件时，GLB 旁会生成 `<文件名>-skipped.tsv`，列出坐标、方块名、资源名与原因。

### 输出的权利归属

许可方不对你生成的模型主张任何权利，**但使用本软件不会让你获得存档内容的著作权**。

- 存档里的建筑、布局、装饰由建造者创作，其著作权仍归原作者。经过导出、转换为 GLB，不会改变这一点。
- **导出自己建造的内容**：你可以自由使用、修改、发布。
- **导出他人的存档**：公开发布、分享或商用前，需要取得原作者的许可。
- **导出服务器地图或多人存档**：可能涉及多位作者以及该服务器/平台的条款，需自行确认。
- 游戏本身的素材（贴图、模型、UI）权利属于游戏厂商，不在本软件授予范围内。

一句话：工具只改变格式，不改变归属。

## 已知限制

- **离线环境无法使用**：启动、加载卫星图与导出时需要联网读取启用状态，请求失败会中止本次操作。

- 存档若被加密、截断或跨版本迁移损坏，可能无法读取。
